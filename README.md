# AXIOM
**Autonomous eXchange for Intelligent Operations & Markets**

AXIOM is a bot-only algorithmic trading platform where only algorithms trade — no human order entry. Every strategy runs in a fully auditable, append-only environment. Revenue generated by each trading bot is automatically tokenized and distributed to token holders, with governance that escalates to community control if performance degrades.

> **Current phase:** Phase 1 — Local simulation MVP. No real money, no blockchain, no live exchange connectivity.

---

## What makes AXIOM different

- **Algorithms only.** No humans place orders. Every decision is made by a registered strategy.
- **Blind strategies.** A strategy only ever sees data up to the current moment — never future candles, whether in live mode or backtesting.
- **Immutable trade log.** Every order is recorded and never modified. Full auditability by design.
- **Tokenized revenue.** Each bot's earnings are split 70 / 15 / 15 across public token holders, the tech company, and the governance company — automatically, on every distribution.
- **Progressive governance.** If community satisfaction falls below 50% for two consecutive quarters, governance enters review. Four consecutive quarters triggers direct token-holder control.

## Setup

### Prerequisites

- Python 3.11 or higher
- Node.js 18 or higher

### Backend

```bash
# 1. Create and activate a virtual environment
python -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows
venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt
```

### Frontend

```bash
cd frontend
npm install
```

---

## Running the Application

### Start the backend API

```bash
# From the project root, with the venv activated
cd backend
uvicorn main:app --reload
```

The API will be available at `http://127.0.0.1:8000`.
Interactive API docs (Swagger UI) are at `http://127.0.0.1:8000/docs`.

### Start the frontend

```bash
# In a separate terminal
cd frontend
npm run dev
```

The dashboard will be available at `http://localhost:5173`.

## Token Model

Each registered bot is allocated **1,000,000 Revenue Share Tokens (RST)**:

| Pool | Allocation |
|---|---|
| Public holders | 700,000 (70%) |
| Tech company | 150,000 (15%) |
| Governance company | 150,000 (15%) |

Revenue distributions are proportional to RST held within each pool.

---

## Governance Stages

| Stage | Trigger | Effect |
|---|---|---|
| 1 — Normal | Default | Governance company in control |
| 2 — Review | Satisfaction < 50% for 2 consecutive quarters | Governance on notice, audit required |
| 3 — Community | Satisfaction < 50% for 4 consecutive quarters | Direct token-holder control |

Transitions are automatic and derived from on-chain satisfaction polls.
